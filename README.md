# Barcode Detection

## Описание

Скрипт выполняет следующие шаги:

1. Загружает изображение, путь к которому вводит пользователь.
2. Переводит изображение в оттенки серого.
3. Вычисляет градиенты по X и Y с помощью Sobel.
4. Вычитает Y-градиент из X-градиента для усиления горизонтальных линий штрих-кода.
5. Размывает изображение и бинаризует его.
6. Применяет морфологическое закрытие для объединения полос штрих-кода.
7. Выполняет эрозии и дилатации для удаления шумов.
8. Находит контуры и выбирает самый большой (предполагаемый штрих-код).
9. Рисует ограничивающий прямоугольник вокруг найденного штрих-кода.
10. Выводит оригинальное изображение и результат.

## Тестовые изображения

* В папке `test_img` находятся тестовые изображения для проверки работы скрипта.
* Пример изображения: `test_img/1.jpg`.

## Использование

1. Клонируйте репозиторий или скачайте скрипт.
2. Установите зависимости (см. `requirements.txt`).
3. Запустите скрипт:

```bash
python detect_barcode.py
```

4. Введите путь к изображению, например:

```
test_img/1.jpg
```

5. Скрипт покажет:

   * оригинальное изображение
   * изображение с обведённым штрих-кодом
